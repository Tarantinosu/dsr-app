# DSR — บันทึกในเบราว์เซอร์

ใช้เว็บเดิม https://tarantinosu.github.io/dsr-app/ จัดการโปรเจกต์ ใบเสนอราคา งวดชำระ เอกสาร และไฟล์แนบ โดยไม่ต้องเชื่อม Google หรือสร้างโฟลเดอร์เก็บข้อมูล

- เพิ่ม/แก้/ลบเป็นฉบับร่าง แล้วกด **บันทึกทั้งหมด** เพื่อเก็บในเบราว์เซอร์นี้
- Refresh อ่านเฉพาะข้อมูลที่บันทึกในเบราว์เซอร์ ไม่เชื่อมบริการภายนอก
- ตั้งค่า → **ดาวน์โหลด Backup** เพื่อสำรองข้อมูลและไฟล์แนบเป็น JSON
- ตั้งค่า → **กู้คืนจากไฟล์** เพื่อนำสำเนากลับมา การกู้คืนแทนข้อมูลปัจจุบัน จึงควรสำรองก่อน
- ไฟล์แนบใหม่อยู่ในฐานข้อมูลเดียวกับรายการเอกสาร และรวมใน Backup; ลิงก์ไฟล์ภายนอกที่บันทึกไว้เดิมยังเปิดได้

ข้อมูลต่างเครื่อง ต่างเบราว์เซอร์ หรือโหมดไม่ระบุตัวตนจะเก็บแยกกัน เว็บนี้ไม่มีการซิงก์ข้ามอุปกรณ์ อย่าล้าง Site data หรือถอนโปรไฟล์เบราว์เซอร์ก่อนสำรองข้อมูล
AI เป็นเครื่องมือเสริมที่ผู้ใช้สั่งเรียกเอง ไม่จำเป็นต่อการบันทึกหรือออกเอกสาร

## อัปเดตจากรุ่น Google

ใช้ URL และโปรไฟล์เบราว์เซอร์เดิม ฐานข้อมูล `DSR_Offline_DB` และรหัสรายการไม่เปลี่ยน รุ่นนี้ไม่อ่านหรือส่งคิว `DSR_Hybrid_Sync_DB` และไม่ล้างคิวเก่า ไม่เขียน Google Sheet ไม่ใช้ Google Drive และไม่บันทึกไฟล์สำเนาลงโฟลเดอร์อัตโนมัติ การเชื่อมต่อ/โฟลเดอร์เก่าไม่ถูกเปิดใช้งานอีก
ไม่ต้องนำเข้า Backup ซ้ำถ้าข้อมูลเดิมในเบราว์เซอร์ครบแล้ว ไฟล์ข้อมูลที่ผู้ใช้ส่งในแชตไม่ได้ถูกรวมเข้าเว็บสาธารณะ
คู่มือ Google รุ่นเก่าในประวัติ repository ไม่ใช้กับรุ่นนี้

## พัฒนาและทดสอบ

ไม่มีขั้นตอน build หรือ npm install:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node manual-save.test.cjs
python3 -m unittest discover -s tests -v
```

Browser tests ต้องมี Python Playwright และ Chromium ที่ `/usr/bin/chromium` ในสภาพแวดล้อมพัฒนานี้ ใช้ข้อมูลจำลองและปิดคำขอ HTTPS ภายนอก ไม่แก้บัญชีหรือข้อมูลจริง
